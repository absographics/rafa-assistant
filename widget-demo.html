Test Shop

A plain stand-in shop page — for trying the website connection end-to-end

This page pretends to be a shop's website. The chat widget in the bottom-right corner is the assistant's Website connection — the same widget a shop gets from the owner app's Connections section.

Try it

Tap 💬 Chat and ask things a customer would ask:

• “Farshi suit ka price kya hai?”
• “Show me the price list”
• “COD available hai?”
• “How do I order?”

The answers come from the connected shop's own live catalogue (rafacollection.com in this demo) — prices are never typed by hand.

How a real shop gets this

The owner connects their website in the assistant app, copies one line of code into their site, and this chat window appears — connected to the assistant's backend, answering every visitor.
